# entry-u-0xkianno-one-word-from-grandma-f04bed16 — One Word From Grandma

One word for make.fun's "One Word From Grandma" bounty: the word a
grandma would text about AI.

> BEEPBOOP

Why it should win: it is grandma playfully imitating the robot
itself — warm, a little baffled, tied to machines rather than any
subject — and fresh where "robot" would be the obvious pick. The
capitals are her caps-lock typing voice, the way she would type it
excitedly to a grandchild. One word, 8 characters.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13 standard library only, no network, no
randomness) writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(falling back to `$MAKEFUN_OUTPUT`, then `/output`) and asserts the
competition's gate itself: exactly one word, 1–30 characters. The
word is a fixed string, so two runs produce identical bytes.
